# CRAVA! · dados dos jogos

Campeonatos que o app **CRAVA! Palpites com a Turma** busca para mostrar jogos e resultados atualizados.

- `manifest.json`: data da última atualização e lista de arquivos.
- `<campeonato>.json`: um arquivo por campeonato (mesmo formato de `data/real/*.json` do app).

Atualizado pela tarefa "Atualizar jogos do CRAVA!" a partir de fontes públicas. Não edite à mão.
